## 📌 Лабораторные работы

### ✅ Лабораторная работа №1: "Базовый роутер" (Home Router)

**Цель:** Настроить виртуальный маршрутизатор MikroTik CHR для раздачи интернета в локальную сеть.

**Что было сделано:**
1. Создан программный коммутатор (Bridge) на порту LAN.
2. Назначен шлюз (Gateway) `192.168.56.2/24`.
3. Поднят DHCP-сервер для автоматической выдачи адресов.
4. Настроен NAT (Masquerade) для трансляции адресов в интернет.
5. Решена проблема маршрутизации на уровне ОС Windows (таблица маршрутов).

**Достижения:**
- ✅ Пинг с хостовой машины на шлюз MikroTik (T=1ms).
- ✅ Выход в интернет через виртуальный роутер.

**Файлы:**
- `configs/router-home.rsc` — Готовая конфигурация для импорта.

### ✅ Лабораторная работа №2: "Базовый Firewall" (Правила безопасности)

**Цель:** Защитить маршрутизатор от несанкционированного доступа из внешней сети (WAN).

**Изученные концепции:**
- Цепочки `Input`, `Forward`, `Output` в RouterOS.
- Состояния соединений (`Established`, `Related`, `Invalid`).
- Принцип "Белого списка" (Запрещено всё, что не разрешено).
- Защита встроенных сервисов (WinBox/SSH) от атак из интернета.

**Результат:**
- ✅ Доступ к роутеру разрешен только из локальной сети (LAN).
- ✅ Запрещен прямой доступ к роутеру из интернета (WAN).
- ✅ Локальная сеть имеет беспрепятственный выход в интернет.

**Файлы:**
- `configs/router-firewall.rsc` — Готовая конфигурация для импорта.
