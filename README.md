# Лаборатория (MikroTik Lab)
Этот репозиторий содержит мои практические наработки по настройке сетевого оборудования на базе RouterOS (MikroTik).
## 📌 Лабораторная работа №1: "Базовый роутер" (Home Router)
**Цель:** Настроить виртуальный маршрутизатор MikroTik CHR так, чтобы он раздавал интернет на виртуальную локальную сеть.
**Схема сети:**
`[Интернет] -> (ether1 WAN) [MikroTik] (ether2 LAN) -> [Локальная сеть]`
**Что было сделано:**
1.  Настроен программный коммутатор (Bridge) на порту LAN.
2.  Назначен шлюз (Gateway) `192.168.56.2/24`.
3.  Поднят DHCP-сервер для автоматической выдачи адресов.
4.  Настроен NAT (Masquerade) для трансляции адресов в интернет.
5.  Решена проблема маршрутизации на уровне ОС Windows (таблица маршрутов).
**Достижения:**
*   ✅ Пинг с хостовой машины на шлюз MikroTik (T=1ms).
*   ✅ Выход в интернет через виртуальный роутер.
**Файлы:**
*   `configs/router-home.rsc` - Готовая конфигурация для импорта.
